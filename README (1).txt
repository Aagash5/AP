Pravarthika & Aagash — Invitation Website (Real Images)
========================================================

This version uses the uploaded real PNG invitation images.

Image order used
----------------
01-opening.png        -> pastel Ganesha / PA monogram opening
02-nichayadhartham.png-> temple mandap sunset background
03-pathirigai.png     -> Venkatachalapathy invitation frame
04-registration.png   -> western rings registration background
05-rsvp.png           -> gold rings RSVP background
06-closing.png        -> bronze-brown closing background

Main files
----------
- index.html
- rsvp-google-apps-script.gs
- assets/*.png

To connect Google Sheets RSVP
-----------------------------
Deploy the Apps Script as a Web App and paste the /exec URL into RSVP_ENDPOINT inside index.html.
